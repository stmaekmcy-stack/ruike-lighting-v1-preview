# ICP 备案执行清单（上海企业）

> 本文档是上线执行清单，不替代腾讯云和上海市通信管理局的最终审核要求。实名身份、证件和法律承诺必须由企业责任人真实填写。

## 备案前提

- [ ] 腾讯云账号已完成与备案主体一致的企业实名认证。
- [ ] 域名已完成实名认证，所有者与备案主体一致，有效期大于 3 个月。
- [ ] 腾讯云中国大陆服务器为包月或包年资源，已购买至少 3 个月，且剩余有效期不少于 1 个月。
- [ ] 服务器具有公网 IP 和大于 0 Mbps 的公网带宽。
- [ ] 已确认网站在 ICP 审核通过前不对外开放。

腾讯云当前入门轻量应用服务器页显示 2 核 2 GB、40 GB SSD、3 Mbps、200 GB/月流量，约 45 元/月或 459 元/年。对 V1.0 静态站和低频咨询接口足够；结算价以购买页为准。参考：[腾讯云建站与轻量应用服务器](https://cloud.tencent.com/product/domain)。

## 提交与审核

1. 在[腾讯云 ICP 备案控制台](https://console.cloud.tencent.com/beian) 开始首次备案。
2. 按页面如实填写主体与网站信息，上传真实证件。
3. 完成腾讯云初审；官方说明的一般初审时间为 1–2 个工作日。
4. 收到工信部短信后 24 小时内完成验证。
5. 等待上海市通信管理局审核；法定审核时限最长可达 20 个工作日。
6. 审核通过后，将真实 ICP 备案号写入网站配置并链接至工信部备案系统，再开放生产站。
7. 网站开通后 30 日内完成公安联网备案，只在取得真实备案号后展示。

## 不可自动代填的信息

统一社会信用代码、法定代表人姓名与证件、网站负责人姓名与证件、手机号、应急电话、人脸核验、短信验证码、法律承诺。
